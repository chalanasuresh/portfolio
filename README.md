# Chalana M S — Personal Portfolio

A modern, responsive personal developer portfolio website for **Chalana M S**, Computer Science & Engineering Student and Aspiring Software Engineer.

---

## 🚀 Features

- **Professional Dark Theme**: Obsidian/slate background with cyan & indigo ambient lighting, glassmorphic cards (`backdrop-filter: blur`), and clean typography.
- **Dynamic Hero Section**: Interactive typewriter effect highlighting roles, live status badge, quick metrics (8.77 CGPA, 3+ certifications), and a stylized 3D developer portrait.
- **About Section**: Clear summary, core competencies (Software Development, Problem Solving, Practical Solutions), location, and multilingual proficiencies (English, Kannada, Hindi).
- **Interactive Skills Section**: Categorized into Programming & SQL, Web & Developer Tools, and Professional Leadership, with dynamic category filtering.
- **Education Timeline**: Chronological milestones with highlighted academic scores:
  - B.E. Computer Science — Navkis College of Engineering (CGPA 8.77)
  - PUC PCMB — Government Pre-University College for Girls (92.3%)
  - SSLC — Government High School (94.08%)
- **Featured Project Showcase**: Full breakdown of **CodeSync — Real-Time Collaborative Coding Platform**, including high-definition mockup window, feature list, architecture modal, and tech stack tags.
- **Verified Certifications**: Dedicated cards for NPTEL (Python), Infosys Springboard (DSA), and Zysk Technologies (Industrial Workshop).
- **Achievements & Leadership**: Honors for IMPROVF Contest Winner, TechSpark Technical Club Treasurer & Social Media Head, Corporate Insight Program, and Hackathons.
- **Interactive Contact**: Direct contact cards with one-click copy-to-clipboard for Email and Phone, LinkedIn connection link, and an interactive contact form with real-time validation and mailto dispatch.

---

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5 (SEO & schema.org JSON-LD included)
- **Styling**: Modern Vanilla CSS with CSS custom properties, glassmorphism, and responsive breakpoints
- **Interactivity**: Vanilla JavaScript (no external runtime dependencies)
- **Icons**: Scalable inline SVGs for fast loading and zero broken external CDNs
- **Server**: Lightweight zero-dependency Node.js HTTP server
